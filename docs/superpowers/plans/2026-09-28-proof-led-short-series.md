# Proof-led short series pilot — implementation plan

**Goal:** Render ten self-contained vertical clips, five for Clipflow and five for MStudio Web, with real first-party screens as evidence. Each series has one cinematic hero and four repeatable episodes suitable for YouTube Shorts and TikTok.

1. Verify first-party claims and capture mobile screens: Clipflow idea, script, preview/export; MStudio home, pricing, service or contact sections. Save reusable image assets and a source log. Do not include client work or imply unfinished capabilities.
2. Extend Remotion's cinematic story scene with a proof-screen treatment that presents captured screens legibly, with kinetic labels and clear safe zones. Keep existing clips rendering unchanged.
3. Create a dedicated ten-clip batch with episode-specific scripts, phrase captions, voiceovers, brand music, real-screen scene assets and platform post copy. One hero per brand gets the most cinematic pacing.
4. Render and QA all ten: status, duration, audio loudness, frame contact sheets, caption legibility and safe zones; fix any failures.
5. Package videos, covers, YouTube Shorts and TikTok post copy in a dated ready-to-post folder. Run relevant tests/build, commit implementation and pilot spec, then show the result in Codex.

**Acceptance:** Ten playable 1080×1920 MP4s, five per brand; every episode includes a real app/site screen; factual copy matches the captured first-party state; no unapproved client work; same export works for both platforms.
