# Adaptive motion correction

This corrects the existing Transformation + Proof brief: diagrams must explain the scene rather than appear because a beat occupies a particular index.

Canvas and Remotion now share a pure direction policy. It reads the full video copy, scene role, selected medium, subject keywords, actual named steps, and approved evidence. A hook no longer automatically implies a transformation. Process and comparison graphics require named steps or states; incidental words such as “from”, “make”, or “first” do not supply diagram labels.

Subject showcases and video footage favor animated typography, restrained edge emphasis for a named detail, or clear footage. Stated values receive a number reveal containing the supplied value rather than invented chart data. Unsupported scenes fall back to typography. Labels for supported diagrams come from the actual phrases rather than the first three keywords.

New Remotion treatments use automatic direction and omit canned brand diagrams. Existing explicit overrides and legacy treatments remain editable. The editor offers automatic direction, typography, focus, metric, and footage-only options and explains automatic selections. Canvas snapshots the same media-aware plan for preview and export; video captions sit below the subject and footage receives a lighter scrim without the continual extra zoom.

The animation primitives are deterministic Canvas and SVG components. This change does not generate arbitrary animation code with a model; it chooses supported compositions based on content. Topic classification and detail focus are editorial heuristics, not visual object tracking.
